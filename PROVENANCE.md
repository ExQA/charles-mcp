# Provenance

This repository is a team fork of [heizaheiza/Charles-mcp](https://github.com/heizaheiza/Charles-mcp),
which is distributed under the MIT License; that copyright notice is kept in [LICENSE](LICENSE).
The upstream project was itself initially inspired by
[tianhetonghua/Charles-mcp-server](https://github.com/tianhetonghua/Charles-mcp-server).

The fork adds data-driven mocks (Map Local files and a body-aware dispatcher), removes the
upstream compatibility layer, and keeps its human documentation in Ukrainian alongside the
English originals.

The Git history of this fork starts from a single commit: the upstream history was not carried
over. This file is the provenance record instead.
