Mock by request body, not just by URL

One Map Remote rule per domain. Every path, action and status after that is data.

App request
POST /api/v1/wallet Host: api.example.com { "action": "get_balance" }
Same URL for every operation. Map Local can only replace all of them, always with 200.
Charles → dispatcher
https://*.example.com/api/* → 127.0.0.1:18080

Rules live in ~/charles-mocks/_rules as JSON — never in your code. The agent builds them from a captured request and changes only the fields you name.
