# Хаб документації

Ця сторінка — основна точка входу в документацію `charles-mcp` українською.

## Мапа документів

- [README.md](../README.md): призначення проєкту, встановлення, швидкий старт (основний README, українською)
- [README.en.md](../README.en.md): те саме англійською
- [AGENTS.uk.md](../AGENTS.uk.md): глобальні правила поведінки агента
- [Посібник для агентів](./agent-guide.uk.md): що сервер передає агентам (MCP instructions + ресурс `charles-mcp://agent-guide`), українською
- [Мапінг і перезапуск Charles](./charles-mapping.uk.md): як працюють правила Map Local і Map Remote, коли потрібен перезапуск Charles, відкат, діагностика
- [ADR-0001](./adr/0001-data-driven-body-aware-mocks.uk.md): чому моки за тілом запиту — це правила-дані та локальний диспетчер
- [ADR-0002](./adr/0002-offline-archive-distribution.uk.md): чому форк роздається архівом, який несе власні колеса
- [Встановлення для команди](./team-installation.uk.md): встановлення форку на інший комп'ютер, правила безпеки, діагностика
- [Сценарії для агента](./agent-workflows.uk.md): покрокові сценарії під задачі
- [Контракт інструментів](./contracts/tools.uk.md): канонічний публічний набір інструментів і контракт кожного з них
- [Як це працює](./how-it-works.uk.html): схеми перехоплення трафіку, трьох джерел відповіді та будови правила, плюс налаштування Kiro (HTML-сторінка, відкривається у браузері)

Основний README — український. Решта українських файлів (`*.uk.md`) — переклади: англійські оригінали (`README.en.md`, `AGENTS.md`, `docs/*.md` без суфікса `.uk`) лишаються джерелом істини для агентів, і саме на них зав'язані контрактні тести.

## Зони відповідальності

- Встановлення та налаштування клієнтів — у README.
- Глобальні правила поведінки агента — в `AGENTS.md`.
- Послідовності викликів — у `docs/agent-workflows.md`.
- Контракт публічного API та інструментів — у `docs/contracts/tools.md`.
